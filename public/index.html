jsonfake

Arquivos JSON servidos como API REST, só leitura.

Como adicionar uma base
  1. Crie db/nome.json no repositório.
  2. Use um objeto na raiz, com arrays de objetos que tenham id.
  3. Faça commit e deploy. A rota /nome/recurso aparece aqui.
